    Amélioration 1 - Gérer les délais

    Présentement les délais de chaque objet sont générés dans la méthode Update. Cette façon de faire est plutôt innefficace, car il se peut que pendant un moment on ait pas besoin d'exécuter le code. Ce qui serait utile, c'est d'avoir une méthode Update qui s'exécute seulement pendant la période de temps où l'on en a besoin : la coroutine.

    Pour le projectile, la coroutine ne sera pas très utile, puisque le délai correspond à la durée de vie de l'objet. Toutefois, pour la tour, en gérant le délai de tir avec un coroutine, on pourra écouter le délai seulement lorsqu'il y a une cible active. On crée donc une méthode pour attaquer et une coroutine qui appelle périodiquement cette méthode tant qu'il y a une cible. Le code qui affecte une cible lorsque celle-ci serait autrement nulle est l'endroit où l'on déclenche la coroutine.

    using System.Collections;
using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// Lanceur d'une tour qui permet de lancer des projectiles vers les ennemis.
/// </summary>
public class Lanceur : MonoBehaviour
{
    // Liste des cibles à portée
    private List<EnnemiFactice> cibles;

    // Cible actuellement attaquée par la tour
    private EnnemiFactice cibleActive;

    [SerializeField, Tooltip("Prefab du projectile de la tour")]
    private Projectile prefabProjectile;

    [SerializeField, Tooltip("Delais entre chaque attaque (en secondes)")]
    private float delaiAttaque;

    private void Awake()
    {
        cibles = new List<EnnemiFactice>();
    }

    /// <summary>
    /// Déclenche l'attaque de la tour en instanciant un projectile et en le dirigeant vers la cible active.
    /// </summary>
    private void Attaquer()
    {
        Projectile projectile = Instantiate(prefabProjectile, transform.position, Quaternion.identity);
        projectile.Initialiser(cibleActive.gameObject);
    }

    /// <summary>
    /// Coroutine qui gère l'attaque répétée de la tour tant qu'une cible est présente.
    /// </summary>
    /// <returns>IEnumerator pour la coroutine</returns>
    private IEnumerator CoroutineAttaque()
    {
        while (cibleActive != null)
        {
            Attaquer();
            yield return new WaitForSeconds(delaiAttaque);
        }
    }

    /// <summary>
    /// Lorsqu'un objet entre dans le collider de la tour, on vérifie s'il s'agit d'un ennemi et on l'ajoute à la liste des cibles.
    /// </summary>
    /// <param name="autreObjet">Le collider de l'objet entrant</param>
    private void OnTriggerEnter(Collider autreObjet)
    {
        if(autreObjet.TryGetComponent(out EnnemiFactice ennemi)) {
            cibles.Add(ennemi);

            // Aucune cible n'est actuellement attaquée, on attaque la première cible qui entre dans la zone
            if (cibleActive == null)
            {
                cibleActive = ennemi;
                StartCoroutine(CoroutineAttaque());
            }
        }
    }

    /// <summary>
    /// Lorsqu'un objet sort du collider de la tour, on vérifie s'il s'agit d'un ennemi et on le retire de la liste des cibles.
    /// </summary>
    /// <param name="autreObjet">Le collider de l'objet sortant</param>
    private void OnTriggerExit(Collider autreObjet)
    {
        if (autreObjet.TryGetComponent(out EnnemiFactice ennemi))
        {
            cibles.Remove(ennemi);

            // La cible attaquée sort de la zone, on passe à la prochaine cible si elle existe
            if (cibleActive == ennemi)
            {
                if (cibles.Count > 0)
                {
                    cibleActive = cibles[0];
                }
                else
                {
                    cibleActive = null;
                }
            }
        }
    }
}

    Amélioration 2 - Réutiliser les objets

    Le danger avec beaucoup de projectiles est de ralentir le jeu avec une création et destruction excessives d'objets. La page sur les pool d'objets offre une solution à ce problème. Nous ferons donc un gestionnaire de pool d'objet spécialisé pour les projectiles. La seule chose qu'il faudra ajouter au Projectile est une méthode pour le réinitialiser. Il faut aussi modifier le Lanceur pour qu'il utilise le pool d'objets.

    Le pool d'objet implémente le pseudo-singleton afin d'être facilement accessible. Cela pourrait devenir un problème dans le cas où le projet est de grande taille, mais le projet abc restera de petite envergure. La méthode GetProjectile accède le pool ou crée une nouvelle instance, alors que RecyclerProjectile rend le projectile innactif pour sa réutilisation future.

    using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// Classe qui gère le pool de projectiles pour réutiliser les instances et éviter les instanciations fréquentes.
/// </summary>
public class PoolProjectiles : MonoBehaviour
{
    /// <summary>
    /// Instance unique de la classe PoolProjectiles pour permettre un accès global.
    /// </summary>
    public static PoolProjectiles Instance { get; private set; }

    /// <summary>  
    /// Liste des instances de projectiles disponibles pour le réutiliser
    /// </summary>
    private List<Projectile> instancesDisponibles;

    [SerializeField, Tooltip("Prefab du projectile à utiliser")]
    private Projectile prefabProjectile;

    private void Awake()
    {
        if (Instance == null)
        {
            Instance = this;
        }
        else
        {
            Destroy(gameObject);
        }

        instancesDisponibles = new List<Projectile>();
    }

    /// <summary>
    /// Récupère un projectile disponible dans la liste ou crée une nouvelle instance si nécessaire.
    /// </summary>
    /// <returns>Une instance de projectile.</returns>
    public Projectile GetProjectile()
    {
        // Récupère un projectile disponible dans la liste
        if (instancesDisponibles.Count > 0)
        {
            Projectile projectile = instancesDisponibles[0];
            instancesDisponibles.RemoveAt(0);
            projectile.gameObject.SetActive(true);
            return projectile;
        }
        else
        {
            // Créez une nouvelle instance de projectile si nécessaire
            Projectile newProjectile = Instantiate(prefabProjectile, transform);
            return newProjectile;
        }
    }

    /// <summary>
    /// Replace un projectile dans la liste des instances disponibles pour le réutiliser plus tard.
    /// </summary>
    /// <param name="projectile">Le projectile à recycler.</param>
    public void RecyclerProjectile (Projectile projectile)
    {
        projectile.gameObject.SetActive(false);
        instancesDisponibles.Add(projectile);
    }
}

    On modifie la signature de la méthode Initialiser du Projectile pour qu'elle accepte une position et une rotation initiale. Cela permet de réintialiser la position du projectile dans le monde, ce qui sera utile lorsqu'un projectile sera partagé entre plusieurs tours. Également, on modifie le comportement du projectile lorsqu'il touche un ennemi pour aller se recycler plutôt que de se détruire.
