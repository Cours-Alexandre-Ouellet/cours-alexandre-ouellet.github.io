On va à présent générer des ennemis par vague. Nous ferons un premier système simple de génération d'ennemis par petit groupe, puis nous complexifieront le système selon les besoins. De base, le système de génération aura besoin des composants suivants :

  • Un emplacement de génération et une destination pour les ennemis;
  • Un prefab d'ennemi à générer;
  • Un nombre de vague et d'ennemi par vague; et
  • Un délai entre les ennemis d'une même vague, ainsi qu'un délai entre les vagues.

Donc le script du générateur aura les attributs suivants :

using UnityEngine;

/// <summary>
/// Génère des ennemis à intervalles réguliers et les place dans la scène.
/// </summary>
public class GenerateurEnnemis : MonoBehaviour
{
    [SerializeField, Tooltip("Emplacement où les ennemis sont générés")]
    private GameObject emplacementGeneration;

    [SerializeField, Tooltip("Destination des ennemis")]
    private GameObject destinationEnnemis;

    [SerializeField, Tooltip("Prefab de l'ennemi à générer")]
    private Ennemi prefabEnnemi;

    [SerializeField, Tooltip("Délai entre chaque vague d'ennemis (en secondes)")]
    private float delaiEntreVague;

    [SerializeField, Tooltip("Nombre d'ennemis par vague")]
    private float tailleVague;

    [SerializeField ,Tooltip("Nombre de vagues à générer")]
    private int nombreVagues;

    [SerializeField, Tooltip("Délai entre chaque ennemi généré (en secondes)")]
    private float delaiEntreEnnemi;

    // Est-ce qu'une vague est en cours de génération
    private bool vagueEnCours;

    // Indice de la vague actuelle
    private int indiceVague;

    private void Start()
    {
        vagueEnCours = false;
        indiceVague = 0;
    }

La plupart de ces données seront externalisés dans d'autres classes pour gérer la personnalisation des vagues (délai, taille, type d'ennemi...). Pour bien séparer le travail, il faudra créer deux coroutines :

  1. Une coroutine qui gère la création d'une vague d'ennemi
  2. Une coroutine qui attend entre les différentes vagues d'ennemi

Création d'une vague

Génération d'une vague
/// <summary>
/// Génère une vague d'ennemis en instanciant le prefab d'ennemi à
/// l'emplacement de génération et en les initialisant avec la destination.
/// </summary>
/// <returns></returns>
private IEnumerator GenererVague()
{
    vagueEnCours = true;

    for (int i = 0; i < tailleVague; i++)
    {
        Ennemi ennemi = Instantiate(prefabEnnemi, transform);
        ennemi.Initialiser(destinationEnnemis);

        yield return new WaitForSeconds(delaiEntreEnnemi);
    }

    vagueEnCours = false;
}

On utiliser le booléen vagueEnCours pour signaler que cette coroutine s'exécute. Cette technique peut être utile pour mesurer l'exécution d'une coroutine. Ensuite, on initialise le nombre d'ennemis de la vague et on les positionne au début du parcours. On modifie la création de l'ennemi pour recevoir la destination.

using UnityEngine;
using UnityEngine.AI;

[RequireComponent(typeof(NavMeshAgent))]
public class Ennemi : MonoBehaviour
{
    private GameObject objectif;

    private NavMeshAgent agent;

    private void Awake()
    {
        agent = GetComponent<NavMeshAgent>();
    }

    public void Initialiser(GameObject emplacementGeneration, GameObject objectif)
    {
        this.objectif = objectif;
        agent.enabled = false;

        // Positionnement de l'ennemi
        transform.SetPositionAndRotation(
            emplacementGeneration.transform.position, 
            emplacementGeneration.transform.rotation);

        // Démarrage de l'agent
        agent.enabled = true;
        agent.SetDestination(objectif.transform.position);
    }
}

Le problème du NavMesh

On positionne l'ennemi avec son transform alors qu'il se déplace par un nav mesh agent. Cela utilise deux techniques de déplacements différentes et occasionne des problèmes. Il est nécessaire de désactiver initialement l'agent pour déplacer l'objet, puis activer l'agent.

Les GameObject vides

Dans le cas actuel on peut utiliser des game objects pour gérer les emplacements de destination et de fin. Cela facilite le placement dans le mode du jeu et l'affichage de l'information. Si l'on avait utiliser des coordonnées, on aurait dû créer des Gizmos pour les faire afficher.

Gestion des vagues

Ensuite, on s'assure de créer chaque vague en attendant un certain délai après la création du dernier ennemi de la vague. Lorsque toutes les vagues sont créées, on arrête simplement de créer des ennemis.

/// <summary>
/// Génère les différentes vagues pour un niveau entier
/// </summary>
/// <returns></returns>
private IEnumerator GenererVagueNiveau()
{
    // On utilise l'attribut indiceVague pour gérer cette boucle, on ne l'initialise pas ici
    for(; indiceVague < nombreVagues; indiceVague++)
    {
        StartCoroutine(GenererVague());

        // Attend tant que la variable vagueEnCours est vraie
        yield return new WaitWhile(() => vagueEnCours);
        yield return new WaitForSeconds(delaiEntreVague);   
    }
}

Pool d'objets et atteinte de l'objectif

On peut maintenant améliorer ce script en lui ajoutant un pool d'objet pour recycler les ennemis plutôt que les détruire. Pour se faire, on va ajouter une détection de l'atteinte de la destination de l'ennemi pour qu'il se recycle quant il atteint la destination.

On ajoute le générateur d'ennemi comme une instance accessible à partir du contrôleur de jeu, pluôt que d'en faire un Singleton.

using System.Collections.Generic;
using System.Collections;
using UnityEngine;

/// <summary>
/// Génère des ennemis à intervalles réguliers et les place dans la scène.
/// </summary>
public class GenerateurEnnemis : MonoBehaviour
{
    [SerializeField, Tooltip("Emplacement où les ennemis sont générés")]
    private GameObject emplacementGeneration;

    [SerializeField, Tooltip("Destination des ennemis")]
    private GameObject destinationEnnemis;

    [SerializeField, Tooltip("Prefab de l'ennemi à générer")]
    private Ennemi prefabEnnemi;

    [SerializeField, Tooltip("Délai entre chaque vague d'ennemis (en secondes)")]
    private float delaiEntreVague;

    [SerializeField, Tooltip("Nombre d'ennemis par vague")]
    private float tailleVague;

    [SerializeField ,Tooltip("Nombre de vagues à générer")]
    private int nombreVagues;

    [SerializeField, Tooltip("Délai entre chaque ennemi généré (en secondes)")]
    private float delaiEntreEnnemi;

    // Est-ce qu'une vague est en cours de génération
    private bool vagueEnCours;

    // Indice de la vague actuelle
    private int indiceVague;

    // Liste des ennemis générés dans la scène
    private List<Ennemi> instancesEnnemis;

    private void Start()
    {
        vagueEnCours = false;
        indiceVague = 0;
        instancesEnnemis = new();
        StartCoroutine(GenererVagueNiveau());
    }

    /// <summary>
    /// Génère les différentes vagues pour un niveau entier
    /// </summary>
    /// <returns></returns>
    private IEnumerator GenererVagueNiveau()
    {
        for(; indiceVague < nombreVagues; indiceVague++)
        {
            StartCoroutine(GenererVague());

            yield return new WaitWhile(() => vagueEnCours);
            yield return new WaitForSeconds(delaiEntreVague);   
        }
    }

    /// <summary>
    /// Génère une vague d'ennemis en instanciant le prefab d'ennemi à
    /// l'emplacement de génération et en les initialisant avec la destination.
    /// </summary>
    /// <returns></returns>
    private IEnumerator GenererVague()
    {
        vagueEnCours = true;

        for (int i = 0; i < tailleVague; i++)
        {
            Ennemi ennemi = GenererEnnemi();
            ennemi.Initialiser(emplacementGeneration, destinationEnnemis);

            yield return new WaitForSeconds(delaiEntreEnnemi);
        }

        vagueEnCours = false;
    }

    /// <summary>
    /// Génère un ennemi en utilisant un objet de la liste d'instances si disponible, 
    /// sinon instancie un nouvel ennemi à partir du prefab.
    /// </summary>
    /// <returns>L'instance d'ennemi à utiliser</returns>
    private Ennemi GenererEnnemi()
    {
        if(instancesEnnemis.Count > 0)
        {
            Ennemi instance = instancesEnnemis[0];
            instance.gameObject.SetActive(true);
            instancesEnnemis.RemoveAt(0);

            return instance;
        }

        // On crée un nouvel ennemi si aucun n'est disponible dans la liste
        return Instantiate(prefabEnnemi, transform);
    }

    public void RecyclerEnnemi(Ennemi ennemi)
    {
        instancesEnnemis.Add(ennemi);
        ennemi.gameObject.SetActive(false);
    }
}

using UnityEngine;

/// <summary>
/// Détecteur d'objectifs pour les ennemis. Lorsqu'un ennemi entre dans le trigger,
/// il est recyclé par le générateur d'ennemis.
/// </summary>
public class DetecteurObjectif : MonoBehaviour
{
    private void OnTriggerEnter(Collider other)
    {
        if(other.TryGetComponent(out Ennemi ennemi))
        {
            ControleurJeu.Instance.GenerateurEnnemis.RecyclerEnnemi(ennemi);
        }
    }
}
