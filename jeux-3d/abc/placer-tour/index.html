    À propos de la page

    Signaler une erreur

    Dans cette section, nous allons placer les tours avec un clic de la souris sur les diverses zones de construction disponible. D'abord, nous devrons créer les zones de construction, leur assigner un visuel puis gérer l'événement clic de la souris pour correctement instancier les tours.

    Créer les zones de construction

    Pour créer les zones de construction, nous allons faire un prefab qui contient seulement un BoxCollider vide. Cette boite de collision servira à détecter le clic de la souris sur une zone de construction lorsqu'une tour sera positionnée. On fait dépasser un peu le collider pour assurer que les clics à angle soient bien détectés.

    Ensuite, on ajoutera un indicateur de zone de construction au-dessus de la zone de construction en utilisant un canvas dans le monde (world space). Ce canvas contiendra uniquement une image qui pointe à la caméra. Le fait de faire pointer une image constamment à la caméra est appelé billboard, et Unity n'a pas de méthode pour gérer cela, il faudra donc créer un script pour effectuer cette gestion.

    using UnityEngine;

/// <summary>
/// Assure que le sprite pointe toujours vers la caméra. Utile pour les sprites 2D dans un monde 3D.
/// </summary>
public class Billboard : MonoBehaviour
{
    [SerializeField, Tooltip("La caméra à regarder")]
    private Camera cameraARegarder;

    private void Start()
    {
        if (cameraARegarder == null)
        {
            cameraARegarder = Camera.main;
        }
    }

    private void LateUpdate()
    {
        transform.LookAt(cameraARegarder.transform, Vector3.up);
    }
}

    La méthode LateUpdate est utilisée pour gérer les événements qui n'ont pas d'influence sur le jeu et qui doivent être traités après le positionnement de la caméra. On regroupe les zones de construction dans un même objet pour en faciliter le suivi. On leur ajouter ensuite le tag ZoneConstruction pour pouvoir les identifier lors du clic.

    using UnityEngine;
using UnityEngine.InputSystem;

public class ControleurJeu : MonoBehaviour
{
    /// <summary>
    /// Singleton du contrôleur de jeu.
    /// </summary>
    public static ControleurJeu Instance { get; private set; }

    [field: SerializeField, Tooltip("Référence au PlayerInput pour gérer les entrées")]
    public PlayerInput Controles { get; private set; }

    [field: SerializeField, Tooltip("Référence à la caméra principale")]
    public Camera CameraPrincipale { get; private set; }

    private void Awake()
    {
        if (Instance == null)
        {
            Instance = this;
        }
        else
        {
            Destroy(gameObject);
        }
    }
}

    Préparer l'interface

    On doit ensuite préparer l'interface pour gérer le placement des tours. On ajoutera un canvas pour une interface qui couvre le jeu (overlay). Cette interface devrait créer en même temps un EventSystem qu'il est important de conserver. Avant de commencer à travailler l'interface, il faut ajuster le CanvasScaler afin maintenir la clarté de l'interface lors de changement de résolution.

    Ensuite, il faut importer les images d'éléments dans le jeu et faire le découpage (slicing) des icônes. Puis on crée les panneaux et boutons pour l'affichage des 5 éléments comme suit.

    Instancier la tour

    Une fois l'interface mise en place, on peut commencer à programmer la logique pour placer les tours. D'abord, il faut créer une tour lorsqu'on appuie sur le bouton. Pour l'instant, on ne fera que des tours de l'élément feu. Pour réagir au clic d'un bouton, il faut associer une méthode à l'événement OnClick du composant Button.

    Pour gérer les tours, on fera une classe appelée FabriqueTour dont le rôle sera de gérer la création des tours. Cette classe sera attachée au game object ZonesContruction.

    Déplacer la tour

    À cette étape on crée un tour qui est fixe dans le monde. Pour quelle se déplace avec la souris il faut :

    1. Ajouter une action qui gère le déplacement de la souris
    2. Ajouter une méthode qui détecte où la souris pointe dans le monde
    3. Déplacer la tour à cette position

    On ajoute une action appelée DeplacerSouris qui permet de suivre le mouvement de la souris. Cette action est de type value et son type de contrôle est Vector2. On lui associe un seul binding, la position de la souris (Position [Mouse]).

    /// <summary>
/// Commence le processus de placement d'une tour. Instancie une tour de niveau 1 et la fait suivre la souris.
/// </summary>
public void CommencerPlacement()
{
    tourEnPlacement = Instantiate(prefabTour);

    InputActionAsset actions = controleurJeu.Controles.actions;
    actions["DeplacerSouris"].performed += SuivreSouris;

}

/// <summary>
/// Se désabonne des événements liés au placement de la tour.
/// </summary>
private void DesabonnerEvenements()
{
    if (controleurJeu.Controles == null)
        return;

    InputActionAsset actions = controleurJeu.Controles.actions;
    actions["DeplacerSouris"].performed -= SuivreSouris;
}

/// <summary>
/// Assure que la tour suit la position de la souris sur le terrain. La tour est placée à la position de la souris, 
/// mais ne peut pas être placée sur des zones interdites.
/// </summary>
public void SuivreSouris(InputAction.CallbackContext contexte)
{
    Vector2 positionSouris = contexte.ReadValue<Vector2>();
    Ray rayon = controleurJeu.CameraPrincipale.ScreenPointToRay(positionSouris);

    if (Physics.Raycast(rayon, out RaycastHit infoRaycast, float.MaxValue, LayerMask.GetMask("Carte")))
    {
        tourEnPlacement.transform.position = infoRaycast.point;
    }
}

    Le Raycasting

    À la ligne 32, on appelle la méthode ScreenPointToRay. Cette méthode convertit la position de la souris à l'écran en un rayon en utilisant la position de la caméra comme référence.

    La méthode Raycast a la signature suivante :

    Paramètre Type Description
    ray Ray Le rayon à projeter dans le monde
    out hitInfo RaycastHit Les données sur l'objet frappé par le rayon
    maxDistance float La distance maximale à vérifier pour les collisions
    layerMask int Un masque indiquant avec quels layers le rayon devrait interagir
    Valeur de retour bool Si une collision a été détectée ou non

    Le paramètre hitInfo contient les données sur l'objet frappé par le rayon. Parmi les données de hitInfo on retrouve :

    • transform : le composant Transform de l'objet frappé; et
    • point : le point qui a été frappé par le rayon

    Ajuster les layers

    À ce moment-ci, le rayon va frapper le volume qui contient la caméra. Il pourrait aussi frapper d'autres objets, donc nous allons isoler sur un layer dédié la « Carte ». Sur ce layer nous mettrons la carte, mais pas ses enfants ainsi que les zones de construction et tous les enfants. De cette façon si la souris passe sur un autre objet, celui-ci sera ignoré.

    La méthode GetMask permet de générer correctement le masque qui détecte seulement les objets sur le layer Carte.

 /// <summary>
 /// Assigne la tour à la zone de construction.
 /// </summary>
 public void PlacerTour(InputAction.CallbackContext contexte)
 {
     Vector2 positionSouris = Mouse.current.position.ReadValue();
     Ray rayon = controleurJeu.CameraPrincipale.ScreenPointToRay(positionSouris);

     if (Physics.Raycast(rayon, out RaycastHit infoRaycast, Mathf.Infinity, LayerMask.GetMask("Carte")))
     {
         if (infoRaycast.collider.CompareTag("ZoneConstruction"))
         {
             // Variable locale pour faciliter l'accès
             GameObject zone = infoRaycast.collider.gameObject;

             // Positionne la tour à l'emplacement de la zone de construction.
             tourEnPlacement.transform.position = zone.transform.position;

             // Mets fin au placement de la tour et désactive les zones de construction.
             tourEnPlacement = null;

             DesabonnerEvenements();
         }
     }
 }

    Masquer et afficher les zones de construction

    Finalement, on va s'assurer d'afficher les zones de construction seulement lorsqu'on place une tour et d'afficher seulement celles qui n'ont pas de tour. En faisant cela, on évite de pouvoir placer deux tours dans la même zone. On trouvera toutes les zones de construction en utilisant une recherche dans le code plutôt que de les assigner manuellement dans l'interface.

    using System.Collections.Generic;
using UnityEngine;
using UnityEngine.InputSystem;

/// <summary>
/// Responsable de la création des tours. Elle instancie une tour de niveau 1, la fait suivre la souris, puis la place sur 
/// le terrain lors du clic gauche. Le clic droit annule l'action et détruit la tour.
/// 
/// Si le joueur n'a pas les ressources, la tour n'est pas placée et un message d'erreur est affiché.
/// </summary>
public class FabriqueTour : MonoBehaviour
{
    [SerializeField, Tooltip("Le prefab de la tour à instancier")]
    private GameObject prefabTour;

    [SerializeField, Tooltip("Référence aux zones de construction de tour")]
    private List<GameObject> zoneConstructions;

    /// <summary>
    /// L'instance de la tour en cours de placement. 
    /// </summary>
    private GameObject tourEnPlacement;

    /// <summary>
    /// Alias pour accès rapide au singleton du contrôleur de jeu.
    /// </summary>
    private ControleurJeu controleurJeu;

    private void Start()
    {
        controleurJeu = ControleurJeu.Instance;

        // Remplit les zones de construction avec les enfants qui ont le tag "ZoneConstruction"
        zoneConstructions = new();

        foreach(Transform enfant in transform)
        {
            if (enfant.CompareTag("ZoneConstruction"))
            {
                zoneConstructions.Add(enfant.gameObject);
            }
        }
    }

    private void OnDestroy()
    {
        DesabonnerEvenements();
    }

    #region Gestion des zones de construction
    /// <summary>
    /// Affiche les zones de construction de tour. Ces zones sont activées pour indiquer au joueur où il peut placer une tour.
    /// </summary>
    private void AfficherZonesConstruction()
    {
        // Activer les zones de construction
        foreach (GameObject zone in zoneConstructions)
        {
            zone.SetActive(true);
        }
    }

    /// <summary>
    /// Masque les zones de construction de tour. 
    /// </summary>
    private void MasquerZonesConstruction()
    {
        foreach (GameObject zone in zoneConstructions)
        {
            zone.SetActive(false);
        }
    }
    #endregion

    #region Gestion du placement de la tour

    /// <summary>
    /// Commence le processus de placement d'une tour. Instancie une tour de niveau 1 et la fait suivre la souris.
    /// </summary>
    public void CommencerPlacement()
    {
        tourEnPlacement = Instantiate(prefabTour);
        AfficherZonesConstruction();

        InputActionAsset actions = controleurJeu.Controles.actions;
        actions["ClicGauche"].performed += PlacerTour;
        actions["ClicDroit"].performed += AnnulerPlacement;
        actions["DeplacerSouris"].performed += SuivreSouris;

    }

    /// <summary>
    /// Se désabonne des événements liés au placement de la tour.
    /// </summary>
    private void DesabonnerEvenements()
    {
        if (controleurJeu.Controles == null)
            return;

        InputActionAsset actions = controleurJeu.Controles.actions;
        actions["ClicGauche"].performed -= PlacerTour;
        actions["ClicDroit"].performed -= AnnulerPlacement;
        actions["DeplacerSouris"].performed -= SuivreSouris;
    }

    /// <summary>
    /// Assure que la tour suit la position de la souris sur le terrain. La tour est placée à la position de la souris, 
    /// mais ne peut pas être placée sur des zones interdites.
    /// </summary>
    public void SuivreSouris(InputAction.CallbackContext contexte)
    {
        Vector2 positionSouris = contexte.ReadValue<Vector2>();
        Ray rayon = controleurJeu.CameraPrincipale.ScreenPointToRay(positionSouris);

        if (Physics.Raycast(rayon, out RaycastHit infoRaycast, Mathf.Infinity, LayerMask.GetMask("Carte")))
        {
            tourEnPlacement.transform.position = infoRaycast.point;
        }
    }

    /// <summary>
    /// Assigne la tour à la zone de construction.
    /// </summary>
    public void PlacerTour(InputAction.CallbackContext contexte)
    {
        Vector2 positionSouris = Mouse.current.position.ReadValue();
        Ray rayon = controleurJeu.CameraPrincipale.ScreenPointToRay(positionSouris);

        if (Physics.Raycast(rayon, out RaycastHit infoRaycast, Mathf.Infinity, LayerMask.GetMask("Carte")))
        {
            if (infoRaycast.collider.CompareTag("ZoneConstruction"))
            {
                // Variable locale pour faciliter l'accès
                GameObject zone = infoRaycast.collider.gameObject;

                // Positionne la tour à l'emplacement de la zone de construction.
                tourEnPlacement.transform.position = zone.transform.position;

                // Mets fin au placement de la tour et désactive les zones de construction.
                tourEnPlacement = null;
                MasquerZonesConstruction();

                // On supprime la zone de construction de la liste pour qu'elle ne soit plus affichée.
                zoneConstructions.Remove(zone);

                DesabonnerEvenements();
            }
        }
    }

    /// <summary>
    /// Annule le placement de la tour et détruit l'instance de la tour.
    /// </summary>
    public void AnnulerPlacement(InputAction.CallbackContext contexte)
    {
        if (tourEnPlacement != null)
        {
            Destroy(tourEnPlacement);
            tourEnPlacement = null;
        }

        MasquerZonesConstruction();
        DesabonnerEvenements();
    }

    #endregion
}
