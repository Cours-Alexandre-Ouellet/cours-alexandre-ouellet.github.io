    Signaler une erreur

    Dans cette partie du code, nous ferons tirer les tours sur les ennemis au fur et à mesure qu'ils circulent vers la zone finale.

    Création de la scène de développement

    Pour ce faire, on va simplement faire une scène secondaire dans laquelle on place une tour et un ennemi avec un script jetable pour qu'il se déplace. Le but sera de faire déplacer l'ennemi en ligne droite pour qu'il traverse la zone de contrôle de la tour. On désignera cet ennemi comme EnnemiFactice pour le différencier des ennemis réels que nous ferons plus tard.

    Également, l'ennemi factice devra avoir lui même un collider et un rigidbody pour que les mouvements puissent être détectés. Le script suivant est utilisé pour simuler le mouvement d'un ennemi.

    using UnityEngine;

/// <summary>
/// Ennemi utilisé pour créer la tour. Ne sera pas utilisé dans le jeu final. 
/// </summary>
public class EnnemiFactice : MonoBehaviour
{
    [SerializeField, Tooltip("Vitesse de déplacement en m/s")]
    private float vitesseDeplacement = 2f;

    // Référence au rigidbody de l'ennemi pour appliquer la physique
    private Rigidbody rigidbody;

    private void Start()
    {
       rigidbody = GetComponent<Rigidbody>();
    }

    // FixedUpdate is called once per physics frame
    void FixedUpdate()
    {
        // Déplacer l'ennemi factice vers l'avant à la vitesse spécifiée
        Vector3 deplacement = transform.forward * vitesseDeplacement * Time.fixedDeltaTime;
        rigidbody.MovePosition(rigidbody.position + deplacement);
    }
}

    Détecter l'entrée des ennemis et la sortie des ennemis

    Pour détecter la zone de contrôle de la tour, on peut s'y prendre de plusieurs façons :

    Stratégie Avantage Désavantage
    Mesurer la distance de la tour à tous les ennemis - Lente ou demande des structures de données avancées pour être efficace
    Mesurer la distance de l'ennemi à toutes les tours - Lente et inverse la logique de contrôle
    Utiliser un collider Maintien toujours la liste des ennemis qui sont à portée Demande un algorithme de gestion de données

    Ici, nous prendrons la 3e stratégie, soit l'utilisation d'un collider pour réduire la charge des calculs. Donc sur chaque lanceur dans les tours, nous ajouterons un collider de type SphereCollider pour représenter le rayon de la tour. Il faudra configurer le collider pour qu'il soit de type triggger.

    Ensuite, il faut ajouter un script pour le lanceur pour déterminer lorsqu'un ennemi entre et sort de la portée de ce dernier. Ce script utilise les fonctions OnTriggerEnter et OnTriggerExit pour réagir lorsqu'un ennemi entre ou sort de sa portée. Aussi, il faut s'assurer qu'il s'agisse d'un ennemi, on va donc utiliser la fonction TryGetComponent pour récupérer le composant de l'ennemi.

    using UnityEngine;

/// <summary>
/// Lanceur d'une tour qui permet de lancer des projectiles vers les ennemis.
/// </summary>
public class Lanceur : MonoBehaviour
{
    /// <summary>
    /// Lorsqu'un objet entre dans le collider de la tour, on vérifie s'il s'agit d'un ennemi et on l'ajoute à la liste des cibles.
    /// </summary>
    /// <param name="autreObjet">Le collider de l'objet entrant</param>
    private void OnTriggerEnter(Collider autreObjet)
    {
        if(autreObjet.TryGetComponent(out EnnemiFactice ennemi)) {
            Debug.Log("Un ennemi est entré dans la zone de la tour : " + ennemi.name);
        }
    }

    /// <summary>
    /// Lorsqu'un objet sort du collider de la tour, on vérifie s'il s'agit d'un ennemi et on le retire de la liste des cibles.
    /// </summary>
    /// <param name="autreObjet">Le collider de l'objet sortant</param>
    private void OnTriggerExit(Collider autreObjet)
    {
        if (autreObjet.TryGetComponent(out EnnemiFactice ennemi))
        {
            Debug.Log("Un ennemi est sorti de la zone de la tour : " + ennemi.name);
        }
    }
}

    Pour permettre de gérer la présence de plusieurs ennemis en même temps dans la zone, il faut les sauvegarder. Idéalement, il faut conserver leur ordre d'entrée, donc nous utiliserons une file pour le faire. Par contre, la Queue dans c# ne permet pas d'enlever un élément quelconque, donc on va utiliser une liste que nous utiliserons comme une file.

    La file dans le jeu

    La file fonctionne ici pour cibler le premier ennemi, car tous les ennemis ont la même vitesse et ne peuvent pas entrer puis ressortir de la zone. Dans un jeu complet, une autre stratégie, comme sélectionner l'ennemi avec la plus grande distance parcourue serait approprié pour cibler le premier ennemi.

    using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// Lanceur d'une tour qui permet de lancer des projectiles vers les ennemis.
/// </summary>
public class Lanceur : MonoBehaviour
{
    // Liste des cibles à portée
    private List<EnnemiFactice> cibles;

    // Cible actuellement attaquée par la tour
    private EnnemiFactice cibleActive;

    private void Awake()
    {
        cibles = new List<EnnemiFactice>();
    }

    /// <summary>
    /// Lorsqu'un objet entre dans le collider de la tour, on vérifie s'il s'agit d'un ennemi et on l'ajoute à la liste des cibles.
    /// </summary>
    /// <param name="autreObjet">Le collider de l'objet entrant</param>
    private void OnTriggerEnter(Collider autreObjet)
    {
        if(autreObjet.TryGetComponent(out EnnemiFactice ennemi)) {
            cibles.Add(ennemi);

            // Aucune cible n'est actuellement attaquée, on attaque la première cible qui entre dans la zone
            if (cibleActive == null)
            {
                cibleActive = ennemi;
                Debug.Log("Nouvelle cible : " + ennemi.name);
            }
        }
    }

    /// <summary>
    /// Lorsqu'un objet sort du collider de la tour, on vérifie s'il s'agit d'un ennemi et on le retire de la liste des cibles.
    /// </summary>
    /// <param name="autreObjet">Le collider de l'objet sortant</param>
    private void OnTriggerExit(Collider autreObjet)
    {
        if (autreObjet.TryGetComponent(out EnnemiFactice ennemi))
        {
            cibles.Remove(ennemi);

            // La cible attaquée sort de la zone, on passe à la prochaine cible si elle existe
            if (cibleActive == ennemi)
            {
                if (cibles.Count > 0)
                {
                    cibleActive = cibles[0];
                }
                else
                {
                    cibleActive = null;
                }

                Debug.Log("Nouvelle cible : " + (cibleActive != null ? cibleActive.name : "Aucune"));
            }
        }
    }
}

    Instancier un projectile

    Maintenant que l'on peut tirer sur cible, il faut coder le projectile pour qu'il s'instancie puis atteigne la cible et se détruise. Les projectiles seront à tête chercheuse, autrement il faudrait prévoir le déplacement futur des ennemis et cela demande un code plus complexe.

    Pour instancier un projectile, nous aurons besoin d'un prefab de projectile puis d'appeler la méthode Instanciate pour créer un Game Object qui copie le prefab. On ajoute aussi un script Projectile et une méthode Initialiser pour transmettre les données, car Unity n'offre aucun moyen de le faire autrement.

    [SerializeField, Tooltip("Delais entre chaque attaque (en secondes)")]
private float delaiAttaque;

// Temps écoulé depuis la dernière attaque
private float tempsDepuisDerniereAttaque;

private void Awake()
{
    cibles = new List<EnnemiFactice>();
    tempsDepuisDerniereAttaque = 0.0f;
}

private void Update()
{
    tempsDepuisDerniereAttaque += Time.deltaTime;

    if (cibleActive != null && tempsDepuisDerniereAttaque >= delaiAttaque)
    {
        // Instancier le projectile et l'initialiser avec la cible
        Projectile projectile = Instantiate(prefabProjectile, transform.position, Quaternion.identity);
        projectile.Initialiser(cibleActive.gameObject);
        tempsDepuisDerniereAttaque = 0.0f;
    }
}

    Faire voler le projectile

    Le projectile se déplace en ligne droite vers la position de la cible. On pourrait le coder comme pour le mouvement de la caméra, mais il existe une façon plus simple comme on connait la position finale du déplacement. Il faut utiliser les méthodes d'interpolation linéaire. La méthode MoveTowards prend les paramètres suivants :

    1. La position actuelle;
    2. La position à laquelle on veut se déplacer; et
    3. Le déplacement maximal durant une frame.

    using UnityEngine;

/// <summary>
/// Projectile lancé par la tour pour attaquer les ennemis.
/// </summary>
public class Projectile : MonoBehaviour
{
    // Cible que le projectile doit atteindre
    private GameObject cible;

    [SerializeField, Tooltip("Vitesse du projectile en m/s")]
    private float vitesse = 5.0f; 

    /// <summary>
    /// Initialise le projectile avec la cible à atteindre.
    /// </summary>
    /// <param name="cible">La cible que le projectile doit atteindre</param>
    public void Initialiser(GameObject cible)
    {
        this.cible = cible;
    }

    private void Update()
    {
        if (cible != null)
        {
            transform.position = Vector3.MoveTowards(transform.position, cible.transform.position, vitesse * Time.deltaTime);
        }
        else
        {
            // Si la cible n'existe plus, le projectile continue tout droit
            transform.position += transform.forward * vitesse * Time.deltaTime;
        }
    }
}

    Détruire le projectile

    Pour détruire le projectile, il y a deux possibilités :

    1. Le projectile frappe l'ennemi; et
    2. Le projectile n'a plus de cible et rencontre une autre condition de destruction.

    Pour frapper l'ennemi, ce cas est relativement simple, car il s'agit que de gérer une collision avec l'ennemi. Pour le second cas, soit on utilise une collision avec un objet qui représente les limites du monde ou on lui définit un temps de vie. Pour ce projet, on définira un temps de vie, car cette solution est plus simple à implémenter tout en répondant à nos besoins.

    Le projectile doit posséder un collider en mode trigger comme la physique de la collision n'a pas d'importance.

    using UnityEngine;

/// <summary>
/// Projectile lancé par la tour pour attaquer les ennemis.
/// </summary>
public class Projectile : MonoBehaviour
{
    // Cible que le projectile doit atteindre
    private GameObject cible;

    [SerializeField, Tooltip("Vitesse du projectile en m/s")]
    private float vitesse = 5.0f;

    [SerializeField, Tooltip("Temps de vie maximal du projectile en secondes")]
    private float tempsVieMaximal = 5.0f;

    private float tempsVie;

    private void Awake()
    {
        tempsVie = 0.0f;
    }

    /// <summary>
    /// Initialise le projectile avec la cible à atteindre.
    /// </summary>
    /// <param name="cible">La cible que le projectile doit atteindre</param>
    public void Initialiser(GameObject cible)
    {
        this.cible = cible;
    }

    private void FixedUpdate()
    {
        // Détruire le projectile s'il dépasse son temps de vie maximal
        if (tempsVie > tempsVieMaximal)
        {
            Destroy(gameObject);
        }

        if (cible != null)
        {
            transform.position = Vector3.MoveTowards(transform.position, cible.transform.position, vitesse * Time.deltaTime);
        }
        else
        {
            // Si la cible n'existe plus, le projectile continue tout droit
            transform.position += transform.forward * vitesse * Time.deltaTime;
        }

        // Mettre à jour le temps de vie du projectile
        tempsVie += Time.deltaTime;
    }

    private void OnTriggerEnter(Collider autre)
{
    if (autre.gameObject == cible)
    {
        // Logique de dégâts ou d'effet sur la cible
        Debug.Log("Projectile a touché la cible : " + cible.name);
        Destroy(gameObject); // Détruire le projectile après l'impact
    }
}
}
