La logique de nos tours se complexifie tranquillement. Nous avons maintenant des tours dans 2 états possibles :

  • En construction : le lanceur est désactivé
  • En activité : le lanceur est activé

Toutefois, avec la gestion des coroutines, il y a un cas de figure où deux projectiles sont lancés en même temps. Regardons les lignes de code suivantes :

private void OnTriggerEnter(Collider other)
{
    if (other.TryGetComponent(out Ennemi ennemi))
    {
        cibles.Add(ennemi);

        if (cibleActive == null)
        {
            cibleActive = cibles[0];
            StartCoroutine(CoroutineAttaque());
        }
    }
}

private void ChangerCible()
{
    if (cibles.Count > 0)
    {
        cibleActive = cibles[0];
    }
    else
    {
        cibleActive = null;
    }
}

private IEnumerator CoroutineAttaque()
{
    while (cibleActive != null)
    {
        Attaquer();
        yield return new WaitForSeconds(delaiAttaque);
    }
}

On remarque que la CoroutineAttaque s'exécute tant que la cible active n'est pas nulle, la coroutine elle-même se lance seulement si la cible active est nulle dans la méthode OnTriggerEnter. La seule façon dont une cible peut redevenir nulle est lorsqu'on appelle ChangerCible et qu'il n'y a plus de cibles potentielles. La logique derrière ce code est fiable et intuitivement devrait fonctionner. Il y a cependant un problème de synchronisation.

Lorsque la coroutine détruit un ennemi, disons le dernier du groupe, alors cibleActive devient nulle. Par contre, en raison de la structure de la coroutine, on attend le delaiAttaque avant de faire la vérification pour arrêter la coroutine. Si, pendant cette période, une nouvelle cible entre, la coroutine ne sera pas arrêtée, car à la vérification cibleActive ne sera plus nulle. Au moment où la cible entre (exécution de OnTriggerEnter) cibleActive est nulle donc la coroutine est lancée de nouveau. La conséquence est maintenant que la coroutine s'exécute deux fois.

Aussi, nous voulons éventuellement ajouter un système d'amélioration au jeu, donc un état pendant lequel les tours sont améliorées. Alors, les tours pourront avoir trois états :

  • En construction : le lanceur est désactivé
  • En attaque : le lanceur attaque dès / tant qu'une cible entre dans la zone de contrôle
  • En amélioration : le lanceur est désactivé pour un certain délai

On va gérer l'état sur les tours, car elle contiendra l'information utile pour plusieurs de ces traitements. Toutefois, il y aura une très forte dépendance entre la tour et le lanceur dans cette partie du code.

Intégrer cette machine à état va forcer une reconception complète du système du lanceur. Parmi les changements à apporter :

  • Inversion de la dépendance entre la tour et le lanceur;
  • Retrait de l'événement TourPlacee;
  • Déplacement des propriétés d'attaque et de gestion des cibles dans la tour;
  • Ajout d'événement entre le lanceur et la tour pour gérer les entrées et sortie du lanceur.

Après ces modifications on obtient le système suivant.

using System;
using UnityEngine;

public class Lanceur : MonoBehaviour
{
    #region Evénements pour gérer l'entrée et la sortie des ennemis de la zone de contrôle
    public event Action<Ennemi> EnnemiEntreZone;
    public event Action<Ennemi> EnnemiSortDeZone;
    #endregion

    private void OnTriggerEnter(Collider other)
    {
        if (other.TryGetComponent(out Ennemi ennemi))
        {
            EnnemiEntreZone?.Invoke(ennemi);
        }
    }

    private void OnTriggerExit(Collider other)
    {
        if (other.TryGetComponent(out Ennemi ennemi))
        {
            EnnemiSortDeZone?.Invoke(ennemi);
        }
    }   
}

using System.Collections;
using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// Gère une tour dans le jeu. La tour peut attaquer les ennemis à porter et infliger des dégâts. Cet objet
/// gère également les améliorations de la tour.
/// </summary>
public class Tour : MonoBehaviour
{
    // Propriété du lanceur

    // Liste des cibles à portée de la tour
    private List<Ennemi> ciblesPotentielles;

    [SerializeField, Tooltip("Delais entre chaque attaque (en secondes)")]
    private float delaiAttaque;

    // La cible des attaques de la tour. 
    private Ennemi cibleActive;
    // Fin des propriétés du lanceur

    [SerializeField, Tooltip("Lanceur de projectiles de la tour")]
    private Lanceur lanceur;

    [field: SerializeField, Tooltip("Dégâts infligés par la tour")]
    public float Degats { get; private set; }

    private void Awake()
    {
        ciblesPotentielles = new List<Ennemi>();
    }

    private void Start()
    {
        ControleurJeu.Instance.GenerateurEnnemis.EnnemiRecycle += OnEnnemiRecycle;
    }

    private void OnDestroy()
    {
        ControleurJeu controleurJeu = ControleurJeu.Instance;
        if (controleurJeu != null && controleurJeu.GenerateurEnnemis != null)
        {
            controleurJeu.GenerateurEnnemis.EnnemiRecycle -= OnEnnemiRecycle;
        }

        if (lanceur != null)
        {
            lanceur.EnnemiEntreZone -= OnEnnemiEntreZone;
            lanceur.EnnemiSortDeZone -= OnEnnemiSortDeZone;
        }
    }

    /// <summary>
    /// Place la tour et active le lanceur et les événements pour gérer 
    /// les ennemis entrant et sortant de la zone de contrôle.
    /// </summary>
    public void Placer()
    {
        lanceur.gameObject.SetActive(true);

        lanceur.EnnemiEntreZone += OnEnnemiEntreZone;
        lanceur.EnnemiSortDeZone += OnEnnemiSortDeZone;
    }

    /// <summary>
    /// Un ennemi entre dans la zone de contrôle
    /// </summary>
    /// <param name="ennemi">L'ennemi qui entre dans la zone</param>
    public void OnEnnemiEntreZone(Ennemi ennemi)
    {
        ciblesPotentielles.Add(ennemi);
        if (cibleActive == null)
        {
            cibleActive = ciblesPotentielles[0];
            StartCoroutine(CoroutineAttaque());
        }
    }

    /// <summary>
    /// Ennemi qui quitte la zone de contrôle
    /// </summary>
    /// <param name="ennemi">L'ennemi qui a quitté la zone</param>
    public void OnEnnemiSortDeZone(Ennemi ennemi)
    {
        ciblesPotentielles.Remove(ennemi);
        if (cibleActive == ennemi)
        {
            ChangerCible();
        }
    }

    /// <summary>
    /// Change la cible active de la tour en sélectionnant la première cible de la liste des cibles à portée.
    /// </summary>
    private void ChangerCible()
    {
        if (ciblesPotentielles.Count > 0)
        {
            cibleActive = ciblesPotentielles[0];
        }
        else
        {
            cibleActive = null;
        }
    }

    /// <summary>
    /// Lorsqu'un ennemi est recyclé, on le retire de la liste des cibles si nécessaire 
    /// et on change la cible active si elle correspond à l'ennemi recyclé.
    /// </summary>
    /// <param name="ennemi">L'ennemi qui a été recyclé</param>
    private void OnEnnemiRecycle(Ennemi ennemi)
    {
        if (ciblesPotentielles.Contains(ennemi))
        {
            ciblesPotentielles.Remove(ennemi);
            if (cibleActive == ennemi)
            {
                ChangerCible();
            }
        }
    }

    /// <summary>
    /// Déclenche l'attaque de la tour en instanciant un projectile et en le dirigeant vers la cible active.
    /// </summary>
    private void Attaquer()
    {
        Projectile projectile = PoolProjectiles.Instance.GetProjectile();
        // On prend la position du lanceur pour que le projectile parte de la bonne position
        projectile.Initialiser(cibleActive, lanceur.transform.position, Quaternion.identity, Degats);
    }

    private IEnumerator CoroutineAttaque()
    {
        while (cibleActive != null)
        {
            Attaquer();
            yield return new WaitForSeconds(delaiAttaque);
        }
    }
}

        /// <summary>
        /// Effectue des traitements dans la première frame où l'objet tour est dans cet état.
        /// </summary>
        /// <param name="tour">La tour qui entre dans l'état.</param>
        public virtual void OnEntrer(Tour tour)
        {

        }

        /// <summary>
        /// Effectue des traitements pour chacune des frames où l'objet tour est dans cet état.

        /// <return>L'état de la tour à la prochaine frame.</return>
        public abstract EtatTour OnExecuter(Tour tour);

        /// Effectue des traitements dans la dernière frame où la tour est dans cet état.
        /// </summary>
        /// <param name="tour">La tour qui sort dans l'état.</param>
        public virtual void OnSortir(Tour tour)
        {

        }
    }
}

#region Machine à états de la tour
// État exécuté actuellement par la tour
private EtatTour etatActuel;

// État à exécuter à la frame suivante.
private EtatTour prochainEtat;
#endregion

private void Awake()
{
    //...

    // Initialisation de l'état de la tour
    prochainEtat = new EtatConstruction();
    etatActuel = null;
}

private void Update()
{
    if (prochainEtat != etatActuel)
    {
        prochainEtat.OnEntrer(this);   
    }

    etatActuel = prochainEtat;
    prochainEtat = etatActuel.OnExecuter(this);

    if(etatActuel != prochainEtat)
    {
        etatActuel.OnSortir(this);
    }
}

using System;
using System.Collections.Generic;
using System.Text;

namespace EtatsTour
{
    public class EtatConstruction : EtatTour
    {
        public override EtatTour OnExecuter(Tour tour)
        { 
            if(!tour.EstPlacee)
            {
                // Reste dans l'état de construction
                return this;
            }
            return new EtatAttente();
        }

        public override void OnSortir(Tour tour)
        {
            base.OnSortir(tour);

            Lanceur lanceur = tour.Lanceur;
            lanceur.gameObject.SetActive(true);

            lanceur.EnnemiEntreZone += tour.OnEnnemiEntreZone;
            lanceur.EnnemiSortDeZone += tour.OnEnnemiSortDeZone;
        }
    }
}

État d'attaque

L'état d'attaque effectue une attaque dès qu'un ennemi entre dans la zone contrôlée. Entre les attaques, l'état attend le délai prescrit avant de réattaquer.

Dans la tour, on peut supprimer la coroutine d'attaque, car ce comportement est maintenant géré dans la machine à état. De plus, on ne lance plus d'attaque directement lorsqu'un ennemi entre dans la zone, puisque l'état d'attaque surveille continuellement le changement. Finalement, la méthode Attaquer devient publique pour être appelée à partir de l'état.

using UnityEngine;

namespace EtatsTour
{
    public class EtatAttaque : EtatTour
    {
        public override EtatTour OnExecuter(Tour tour)
        {
            if(tour.TempsDepuisDerniereAttaque >= tour.DelaiAttaque
                && tour.CibleActive != null)
            {
                tour.Attaquer();
                tour.TempsDepuisDerniereAttaque = 0f;
            }

            tour.TempsDepuisDerniereAttaque += Time.deltaTime;

            return this;
        }
    }
}

  • Aucun des problèmes déjà réglés n'a été réintroduit
