    Utiliser cinemachine

    Il faut d'abord installer le package Cinemachine. Ce package permet de gérer plus facilement les mouvements de caméra en offrant plusieurs composants dédiés. Cinemachine ne remplace pas la caméra de Unity. Le principe est que l'on attache le composant Cinemachine Brain à la caméra, puis on crée une caméra Cinemachine qui sera l'objet que l'on va configurer. Le brain, va ensuite traiter cette information pour positionner correctement l'objet caméra dans le jeu.

    Dans le cas du projet ABC, on va utiliser une caméra libre, donc on va avoir un objet (tracking target) qui représentera la cible de la caméra. En déplaçant cet objet dans le jeu, on va pouvoir forcer Cinemachine à suivre cet objet et ainsi avoir un mouvement de caméra. Donc, il faut créer deux Game Objects, un pour la caméra virtuelle, un pour la cible.

    Ensuite, il faut configurer la caméra virtuelle avec trois composants :

    • Cinemachine Camera : crée une caméra virtuelle qui enverra ses informations au Cinemachine Brain
    • Cinemachine Position Composer : permet de suivre la position de la cible
    • Cinemachine Position Composer : permet de suivre la rotation de la cible

    Configure le Cinemachine Camera

    1. On affecte une cible suivie par la caméra. Il s'agit d'y affecter l'objet créer précédemment.
    2. On sélectionne les modes de suivis de position et de rotation. Il existe d'autres modes qui permettent de gérer des caméras guidées pour des cinématiques (dolly), des caméras orbitales ou en 3e personne. Dans notre cas, on va utiliser les valeurs Position Composer et Rotation Composer pour obtenir l'effet de caméra libre.

    Configurer le Cinemachine Position Composer et le Cinemachine Rotation Composer

    1. La distance de la caméra permet de définir la largeur du champ. Un caméra avec une faible distance aura un champ de vision étroit, tandis qu'une caméra avec une haute distance aura un champ de vision large.
    2. Le Target Tracking (position) permet de définir comment la caméra se positionne par rapport à la cible. Le paramètre target offset qui indique la position relative par rapport à la cible. Le paramètre damping indique la force de l'amortissement du mouvement. Une valeur élevée donne un mouvement très décalé, les résultats sont meilleurs avec des valeurs relativement petites.
    3. Le Target Tracking (rotation) fonctionne de la même façon, mais cette fois-ci ce sont des angles en degrés plutôt que des valeurs de distance qu'il faut indiquer.

    Déplacer la cible

    Maintenant que la caméra est configurée pour suivre la cible, il faut ajouter un script pour déplacer cette cible. Pour ce faire, on crée un nouveau script de type MonoBehaviour appelé CibleCamera. Avant de commencer à coder le script, on doit configurer le InputSystem avec les actions suivantes :

    Ne pas toucher au actionMap du UI

    Ensuite, on ajoute un Game Object vide qui contient un composant PlayerInput régler sur notre liste d'actions. Le comportement utilisé dans le projet est Invoke c sharp event. Cette méthode plus avancée, mais dont nous aurons besoin demande de comprendre les bases de la programmation événementielle.

    using Unity.Cinemachine;
using UnityEngine;
using UnityEngine.InputSystem;

/// <summary>
/// Gère les déplacement de la cible de caméra. La caméra est une Cinemachine qui a comme cible ce gameObject.
/// </summary>
public class CibleCamera : MonoBehaviour
{
    [Header("Paramètres de déplacement")]
    [SerializeField, Tooltip("Vitesse de déplacement en m/s")]
    private float vitesseDeplacement; 

    [Header("Références aux objets de jeu")]
    [SerializeField, Tooltip("Le PlayerInput qui gère les actions de la personne qui joue")]
    private PlayerInput controles;

    [SerializeField, Tooltip("Zone de confinement de la caméra")]
    private BoxCollider volumeCamera;

    [SerializeField, Tooltip("La caméra qui suit la cible")]
    private CinemachineCamera cameraGeree;

    // Variables privées pour la gestion du déplacement
    /// <summary>
    /// Le deplacement actuel de la caméra
    /// </summary>
    private Vector2 deplacement;


    private void Start()
    {
        // Action de déplacement
        InputAction actionDeplacement = controles.actions.FindAction("player/DeplacerCamera");
        actionDeplacement.performed += CommencerDeplacement;
        actionDeplacement.canceled += TerminerDeplacement;
    }

    private void Update()
    {
        DeplacerCamera();   
    }

    private void OnDestroy()
    {
        if (controles == null || controles.actions == null) { return; }

        // Retire les callbacks des actions pour éviter les fuites de mémoire
        InputAction actionDeplacement = controles.actions.FindAction("player/DeplacerCamera");
        actionDeplacement.performed -= CommencerDeplacement;
        actionDeplacement.canceled -= TerminerDeplacement;
    }

    #region Déplacement
    /// <summary>
    /// Commence le déplacement de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void CommencerDeplacement(InputAction.CallbackContext contexte)
    {
        Vector2 deplacement = vitesseDeplacement * contexte.ReadValue<Vector2>().normalized;
    }

    /// <summary>
    /// Termine le déplacement de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void TerminerDeplacement(InputAction.CallbackContext contexte)
    {
        deplacement = Vector2.zero;
    }

    /// <summary>
    /// Gère le déplacement de la caméra en fonction de l'input du joueur et des limites du volume de la caméra
    /// </summary>
    private void DeplacerCamera()
    {
        if (deplacement.sqrMagnitude > 0.0f)
        {
            Vector3 prochainDeplacement = transform.right * deplacement.x +
            transform.forward * deplacement.y;

            prochainDeplacement = Vector3.Scale(prochainDeplacement, new Vector3(1.0f, 0.0f, 1.0f));
            prochainDeplacement *= Time.deltaTime;

            transform.position += prochainDeplacement;

        }
    }
    #endregion

    Pour comprendre ce script, on va le parcourir du bas vers le haut.

    Ce script exécute un mouvement de la cible à chaque frame avec la méthode DeplacerCamera appelée du Update. La variable deplacement contient un vecteur 2D avec les données de la personne qui joue sur les touches appuyées. Par exemple, appuyer sur « W » retourne le vecteur \((0, 1)\) qui représente un déplacement vers l'avant, donc forward de l'objet. L'appel de Scale permet de garder le mouvement dans le plan XZ, un problème qui surviendra quand on changera l'inclinaison de la caméra. L'appel de Normalize assure que le vecteur a une longueur unitaire, ce qui évite de se déplacer plus vite en diagonale qu'en ligne droite. On affecte ensuite la position de la cible avec la valeur calculée de la prochaine position.

    Pour changer la valeur de la variable deplacement, on doit regarder les méthodes CommencerDeplacement qui lit la valeur à partir du contrôle bidirectionnelle. La lecture du contexte dans un Vector2 permet de savoir quelles sont les touches appuyées. Lorsqu'aucune touche n'est appuyée, alors le déplacement est nul.

    Dans la méthode Start, on trouve l'action liée au déplacement. Elle est dans la action map player et s'appelle DeplacerCamera, donc son chemin d'accès dans les actions est player/DeplacerCamera. La variable controle contient une référence au PlayerInput. Ensuite, on lie le callback performed au début du déplacement. Si l'on utilise le callback started, le mouvement ne prendra pas en charge les changements de direction. Le callback canceled pour sa part est appelée lorsque toutes les touches sont relâchées. Lorsque l'Input System lancera l'événement que le contrôle DeplacerCamera a eu exécuté, la méthode CommencerDeplacement est appelée. On s'assure de libérer les références dans un OnDestroy pour éviter les erreurs de NullReferenceException.

    Confiner la caméra

    Pour éviter que la caméra ne quitte la zone de jeu, il faut appliquer une méthode de confinement de celle-ci. Avec des valeurs comme des rotations, c'est facile de limiter les valeurs qu'elles peuvent prendre, mais cela est plus complexe en 2D. La technique retenue est de mettre une boîte de collision (BoxCollider) autour du monde. Cette boîte va garder la cible à l'intérieur en provoquant des collisions si la cible essaie de sortir. Plutôt que d'utiliser des collisions physiques, on va plutôt utiliser les limites (bounds) de cette boîte. Toutefois, pour éviter les problèmes avec les autres composants, il est important de configurer ce BoxCollider adéquatement.

    Dans la structure du projet, l'objet qui contient le BoxCollider est Game Object vide enfant du prefab de la carte.

    Le code qui fait cette vérification est le suivant. La variable volumeCamera est le BoxCollider utilisé pour définir les limites du déplacement.

    /// <summary>
/// Gère le déplacement de la caméra en fonction des entrés du joueur et des limites du volume de la caméra
/// </summary>
private void DeplacerCamera()
{
    if (deplacement.sqrMagnitude > 0.0f)
    {
        Vector3 prochainDeplacement = transform.right * deplacement.x +
        transform.forward * deplacement.y;

        prochainDeplacement = Vector3.Scale(prochainDeplacement, new Vector3(1.0f, 0.0f, 1.0f));
        prochainDeplacement *= Time.deltaTime;

        Vector3 prochainePosition = transform.position + prochainDeplacement;

        if (volumeCamera.bounds.Contains(prochainePosition))
        {
            transform.position = prochainePosition;
        }
    }
}

    Les autres mouvements

    Voici la configuration complète de la caméra et le script qui assure un déplacement sur tous les axes ainsi qu'une contrainte de chaque axe. Les idées suivantes sont utilisées pour les contrôles :

    • Rotation : c'est de changer la rotation sur l'axe Y de la cible. La caméra virtuelle veut toujours voir la même face. C'est important de tourner dans l'espace du monde et non dans l'espace local.
    • Inclinaison : c'est d'incliner la cible. La caméra virtuelle veut toujours voir la même face.
    • Zoom : provoquer un déplacement le long de la ligne qui relie la cible à la caméra. Pour s'approcher, on va réduire le offset tracking le long de cette ligne, pour s'éloigner on augmente la distance. La molette de la souris fonctionne par incrément, l'effet de damping va donner un mouvement continu. Il est aussi possible de changer la distance de la caméra, mais l'effet est très saccadé et souvent insatisfaisant.

    using Unity.Cinemachine;
using UnityEngine;
using UnityEngine.InputSystem;

/// <summary>
/// Gère les déplacement de la cible de caméra. La caméra est une Cinemachine qui a comme cible ce gameObject.
/// </summary>
public class CibleCamera : MonoBehaviour
{
    [Header("Paramètres de déplacement")]
    [SerializeField, Tooltip("Vitesse de déplacement en m/s")]
    private float vitesseDeplacement; 

    [SerializeField, Tooltip("Vitesse de rotation en deg/sec")]
    private float vitesseRotation;

    [SerializeField, Tooltip("Vitesse inclinaison en deg/sec")]
    private float vitesseInclinaison;

    [SerializeField, Tooltip("Angles d'inclinaison limites de la caméra. Doit être plus petit que le premier angle ou plus grand que le second")]
    private Vector2 limitesInclinaison;

    [SerializeField, Tooltip("Vitesse zoom de la caméra")]
    private float vitesseZoom;

    [SerializeField, Tooltip("Limites du zoom de la caméra")]
    private Vector2 limitesZoom;

    [Header("Références aux objets de jeu")]
    [SerializeField, Tooltip("Le PlayerInput qui gère les actions de la personne qui joue")]
    private PlayerInput controles;

    [SerializeField, Tooltip("Zone de confinement de la caméra")]
    private BoxCollider volumeCamera;

    [SerializeField, Tooltip("La caméra qui suit la cible")]
    private CinemachineCamera cameraGeree;

    // Variables privées pour la gestion du déplacement
    /// <summary>
    /// Le deplacement actuel de la caméra
    /// </summary>
    private Vector2 deplacement;

    /// <summary>
    /// La rotation actuelle de la caméra
    /// </summary>
    private float rotation;

    /// <summary>
    /// L'inclinaison actuelle de la caméra
    /// </summary>
    private float inclinaison;

    /// <summary>
    /// Le zoom actuel de la caméra
    /// </summary>
    private float zoom;

    private void Start()
    {
        // Action de déplacement
        InputAction actionDeplacement = controles.actions.FindAction("player/DeplacerCamera");
        actionDeplacement.performed += CommencerDeplacement;
        actionDeplacement.canceled += TerminerDeplacement;

        InputAction actionRotation = controles.actions.FindAction("player/TournerCamera");
        actionRotation.performed += CommencerRotation;
        actionRotation.canceled += TerminerRotation;

        InputAction actionInclinaison = controles.actions.FindAction("player/InclinerCamera");
        actionInclinaison.performed += CommencerInclinaison;
        actionInclinaison.canceled += TerminerInclinaison;

        InputAction actionZoom = controles.actions.FindAction("player/ZoomerCamera");
        actionZoom.performed += CommencerZoom;
        actionZoom.canceled += TerminerZoom;
    }

    private void Update()
    {
        DeplacerCamera();
        TournerCamera();
        InclinerCamera();
        ZoomerCamera();       
    }

    private void OnDestroy()
    {
        if (controles == null || controles.actions == null) { return; }

        // Retire les callbacks des actions pour éviter les fuites de mémoire
        InputAction actionDeplacement = controles.actions.FindAction("player/DeplacerCamera");
        actionDeplacement.performed -= CommencerDeplacement;
        actionDeplacement.canceled -= TerminerDeplacement;

        InputAction actionRotation = controles.actions.FindAction("player/TournerCamera");
        actionRotation.performed -= CommencerRotation;
        actionRotation.canceled -= TerminerRotation;

        InputAction actionInclinaison = controles.actions.FindAction("player/InclinerCamera");
        actionInclinaison.performed -= CommencerInclinaison;
        actionInclinaison.canceled -= TerminerInclinaison;

        InputAction actionZoom = controles.actions.FindAction("player/ZoomerCamera");
        actionZoom.performed -= CommencerZoom;
        actionZoom.canceled -= TerminerZoom;
    }

    #region Déplacement
    /// <summary>
    /// Commence le déplacement de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void CommencerDeplacement(InputAction.CallbackContext contexte)
    {
        deplacement = vitesseDeplacement  * contexte.ReadValue<Vector2>().normalized;
    }

    /// <summary>
    /// Termine le déplacement de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void TerminerDeplacement(InputAction.CallbackContext contexte)
    {
        deplacement = Vector2.zero;
    }

    /// <summary>
    /// Gère le déplacement de la caméra en fonction de l'input du joueur et des limites du volume de la caméra
    /// </summary>
    private void DeplacerCamera()
    {
        if (deplacement.sqrMagnitude > 0.0f)
        {
            Vector3 prochainDeplacement = transform.right * deplacement.x +
            transform.forward * deplacement.y;

            prochainDeplacement = Vector3.Scale(prochainDeplacement, new Vector3(1.0f, 0.0f, 1.0f));
            prochainDeplacement *= Time.deltaTime;

            Vector3 prochainePosition = transform.position + prochainDeplacement;

            if (volumeCamera.bounds.Contains(prochainePosition))
            {
                transform.position = prochainePosition;
            }
        }
    }
    #endregion

    #region Rotation
    /// <summary>
    /// Commence la rotation de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void CommencerRotation(InputAction.CallbackContext contexte)
    {
        rotation = vitesseRotation * contexte.ReadValue<float>();
    }

    /// <summary>
    /// Termine la rotation de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void TerminerRotation(InputAction.CallbackContext contexte)
    {
        rotation = 0.0f;
    }

    /// <summary>
    /// Effectue la rotation de la caméra
    /// </summary>
    private void TournerCamera()
    {
        // Important de tourner dans l'espace du monde pour ne pas avoir d'interaction avec l'inclinaison de la caméra
        transform.Rotate(new Vector3(0.0f, rotation * Time.deltaTime, 0.0f), Space.World);
    }
    #endregion

    #region Inclinaison 
    /// <summary>
    /// Commence l'inclinaison de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void CommencerInclinaison(InputAction.CallbackContext contexte)
    {
        inclinaison = vitesseInclinaison * contexte.ReadValue<float>();
    }

    /// <summary>
    /// Termine l'inclinaison de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void TerminerInclinaison(InputAction.CallbackContext contexte)
    {
        inclinaison = 0.0f;
    }

    /// <summary>
    /// Applique l'inclinaison de la caméra en fonction de l'input du joueur et des limites d'inclinaison
    /// </summary>
    private void InclinerCamera()
    {
        float angle = (transform.localEulerAngles.x + inclinaison * Time.deltaTime) % 360;

        if (angle < limitesInclinaison.x || angle > limitesInclinaison.y)
        {
            transform.Rotate(new Vector3(inclinaison * Time.deltaTime, 0.0f, 0.0f), Space.Self);
        }        
    }
    #endregion

    #region Zoom
    /// <summary>
    /// Commence le zoom de la caméra
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void CommencerZoom(InputAction.CallbackContext contexte)
    {
        zoom = vitesseZoom * contexte.ReadValue<float>();
    }

    /// <summary>
    /// Termine le zoom de la caméra    
    /// </summary>
    /// <param name="contexte">Information du callback de l'action</param>
    private void TerminerZoom(InputAction.CallbackContext contexte)
    {
        zoom = 0.0f;
    }

    /// <summary>
    /// Applique le zoom de la caméra en fonction de l'input du joueur
    /// </summary>
    private void ZoomerCamera()
    {
        CinemachinePositionComposer positionComposer = cameraGeree.GetComponent<CinemachinePositionComposer>();
        Vector3 offsetCamera = positionComposer.TargetOffset + positionComposer.TargetOffset.normalized * zoom;
        float distanceCamera = offsetCamera.magnitude;

        if (distanceCamera >= limitesZoom.x && distanceCamera <= limitesZoom.y)
        {
            positionComposer.TargetOffset = offsetCamera;
        }
    }
    #endregion
}
