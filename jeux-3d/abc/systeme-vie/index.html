À propos de la page

Signaler une erreur

Le système de vie permet aux tours de détruire des ennemis et ainsi de prévenir qu'ils atteignent le bout de la carte. Pour mettre en place un tel système, il faudra mettre en place les éléments suivants :

  • Un script de tour qui indique le nombre de dégâts à infliger;
  • Transmettre les informations au projectile en utilisant le lanceur;
  • Un script sur les ennemis pour recevoir les dégâts;
  • Une interface qui affiche les dégâts pour chaque ennemi;
  • Le recyclage des ennemis lorsqu'ils ont été détruits; et
  • Une mise à jour de l'initialisation des ennemis pour restaurer leur vie.

1. Le script de la tour

La tour ne contient pour l'instant... rien. On doit donc créer un nouveau script pour répondre à ce besoin. Pour l'instant, nous ferons qu'un script banal qui expose les dégâts. Par contre, comme le jeu évoluera, le script pourra gérer des comportements plus complexes et l'évolution de la tour.

public class Tour : MonoBehaviour

    [field:SerializeField, Tooltip("Dégâts infligés par la tour")]
    public float Degats { get; private set; }
}

public class Projectile : MonoBehaviour
{
    // Dégâts infligés par le projectile
    private float degats;

    /// <summary>
    /// Initialise le projectile avec la cible à atteindre.
    /// </summary>
    /// <param name="cible">La cible que le projectile doit atteindre</param>
    /// <param name="positionInitiale">La position initiale du projectile</param>
    /// <param name="rotationInitiale">La rotation initiale du projectile</param>
    /// <param name="degats">Les dégâts infligés par le projectile</param>
    public void Initialiser(Ennemi cible, Vector3 positionInitiale, Quaternion rotationInitiale, float degats)
    {
        this.cible = cible;
        this.degats = degats;
        transform.SetPositionAndRotation(positionInitiale, rotationInitiale);
    }

    private void OnTriggerEnter(Collider autre)
    {
        if (autre.gameObject == cible)
        {
            // Logique de dégâts à implémenter dans l'ennemi
            cible.RecevoirDegats(degats);
            PoolProjectiles.Instance.RecyclerProjectile(this);
        }
    }
}

3. Un script pour recevoir les dégâts

Le code précédent nous indique qu'il faut ajouter une méthode (RecevoirDegats) dans l'ennemi pour gérer l'information. Il faudra aussi que notre ennemi possède une vie et une vie maximale pour permettre le calcul et l'affichage de sa vie restante.

Pourquoi des floats ?

On gère la vie ici avec des floats. La raison derrière cette décision est d'ouvrir la porte à un système de modification et d'amélioration tout en gardant les valeurs petites. Par exemple, augmenter de 10 % une attaque de 4 points de dégâts inflige 4.4 points de dégâts. Ce changement, en arithmétique entière, n'aurait aucun effet.

public class Ennemi : MonoBehaviour
{
    [SerializeField, Tooltip("Nombre de points de vie maximaux de l'ennemi")]
    private float vieMaximale;

    // Nombre de points de vie actuels de l'ennemi. Si la valeur tombe à 0, l'ennemi est détruit.
    private float vieActuelle;

    private void Awake()
    {
        agent = GetComponent<NavMeshAgent>();
        vieActuelle = vieMaximale;
    }

    public void RecevoirDegats(float degats)
    {
        vieActuelle -= degats;
    }
}

4. Une interface qui affiche les dégâts pour chaque ennemi

Lorsque l'ennemi est atteint pour la première fois par un projectile, on devrait afficher une barre de progression indiquant la vie restante de l'ennemi et la faire diminuer au fur et à mesure qu'il reçoit des dégâts. Donc chaque ennemi devra avoir son propre UI dans le monde. Pour gérer la barre de progression, il faudra ajouter un script et configurer ce nouveau UI.

using UnityEngine;
using UnityEngine.UI;

/// <summary>
/// Gère l'affichage d'une barre de progression dans l'interface utilisateur.
public class BarreProgression : MonoBehaviour
{
    [SerializeField, Tooltip("Image représentant la barre de progression")]
    private Image barreInterne;

    [SerializeField, Tooltip("Valeur initiale de la barre de progression")]
    private float valeurInitiale = 0.0f;

    private void Start()
    {
        MettreAJourProgression(valeurInitiale);
    }

    /// <summary>
    /// Met à jour la progression de la barre de progression.
    /// </summary>
    /// <param name="progression">La progression de la barre, comprise entre 0 et 1</param>
    public void MettreAJourProgression(float progression)
    {
        barreInterne.fillAmount = Mathf.Clamp01(progression);
    }
}

Quelques problèmes restants

  • Le problème de la tour qui tire sans être placée. Présentement, il n'est pas obligatoire de positionner la tour pour qu'elle tire. Pour remédier à ce problème, nous pouvons utiliser le script tour pour recevoir le message de placement et, le cas échéant, activer le lanceur.

  • Le problème du recyclage. Présentement on retire les ennemis lorsqu'il quitte la zone. Or, lorsqu'ils sont détruits, OnTriggerExit n'est jamais appelé. Il faudra donc envoyer un message aux lanceurs lorsqu'un ennemi est détruit pour qu'il se retire de la liste des cibles.

Pour ces deux problèmes, il faudra utiliser des événements du jeu pour régler ces problèmes de façon élégante en alourdissant un minimum le code.
