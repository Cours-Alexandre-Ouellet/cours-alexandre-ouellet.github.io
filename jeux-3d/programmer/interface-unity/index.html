    Interface

    Dans cette première section, l'interface de Unity sera présentée, ainsi que les principaux contrôles des vues les plus importantes.

    1. La barre de menu comporte les menus suivants :
      • Files : pour enregistrer et construire un exécutable à partir d'un projet;
      • Edit : permet d'accéder aux paramètres du projet et de Unity;
      • Assets / GameObject / Component : permet de gérer les assets, game objects et components, mais plus souvent on retrouve ces options dans le menu contextuel (clic droit) lors de clic dans la vue appropriée ou directement dans l'inspecteur; et
      • Window : permet d'afficher certaines vues ainsi que d'accéder au gestionnaire de package.
    2. La vue de hiérarchie présente la structure de la scène active. On y voit s'afficher les game objects de la scène ;
    3. La vue principale présente l'interface de la scène active (scene), du jeu (game) et du contrôleur d'animation (animator). La vue de la scène et du jeu sont présentées en détail plus bas, celle du contrôleur d'animation sur la page des animations ;
    4. La vue du bas présente plusieurs panneaux utiles dont :
      • Console qui journalise les messages transmis par Unity;
      • Project qui affiche la strucutre de fichiers des Assets du jeu;
      • Animation qui permet de définir les clips d'animation (voir la page des animations); et
      • Audio Mixer qui gère le niveau sonore (voir la page sur l'audio).
    5. L'inspecteur qui présente les informations du game object, du prefab ou de l'asset sélectionné; et
    6. Le bouton Layout qui permet de réorganiser l'interface. En cas de problème d'affichage, simplement réinitialiser la disposition avec ce bouton peut régler le problème.

    La vue de la scène

    1. Défintion du pivot pour manipuler les game objects dans la scène;
    2. Espace de référence des poignées de manipulation des game objects;
    3. Configuration de la grille de référence;
    4. Configuration de l'affichage des objets. De gauche à droite les options sont :
      • Wireframe : affiche seulement les arrêtes des meshes des objets;
      • Shaded wireframe : affiche les arrêtes des meshes par dessus la vue avec un shader;
      • Unlit draw mode : affiche les objets avec un shadder unlit, donc sans contribution de l'éclairage. Peut accéléré la manipulation de la scène ; et
      • Shadded : affiche les objets selon leur shadder, ressemble à ce qui sera affiché lors du jeu.
    5. Permet de couper le son lors du développement;
    6. Affiche les différents gizmos qui aident au développement. La flèche permet de sélectionner quels gizmos sont affichés;
    7. Définit le contrôle des poignées du game object actif;
    8. Affiche ou masque le fenêtre de configuration ou de visualisation de certains composants de l'interface scène. Le denier permet de voir la prévisualisation de la caméra de jeu.
    9. Prévisualisation de la caméra de jeu

    La vue du jeu

    1. Définit la résolution de la présentation. Contient aussi les options pour activer la vsync;
    2. Contrôle l'échelle de présentation du jeu, pour entrer dans l'éditeur il faut généralement rétrécir les éléments;
    3. Mode de lancement du jeu :
      • Play Focused : lorsque le jeu est lancé, l'éditeur bascule sur la fenêtre game;
      • Play Maximized : lorsque le jeu est lancé, l'éditeur bascule sur la fenêtre game et la maximise, masquant les autres panneaux; et
      • Play Unfocused : lorsque le jeu est lancé, l'éditeur reste dans l'affichage dans lequel il est.
    4. Permet de couper le son lors du développement;
    5. Affiche les statistiques, dont le nombre de frames par secondes; et
    6. Permet d'afficher les gizmos dans la fenêtre de jeu.

    L'inspecteur

    1. Permet de changer l'icône affiché dans la vue de la scene;
    2. Permet de changer le nom du game object;
    3. Permet de changer le tag associé au game object;
    4. Permet de changer le layer sur lequel est rendu le game object;
    5. Définir un objet static optimise le jeu, mais l'objet ne sera jamais déplacé durant l'exécution;
    6. Le cadenas permet de verrouiller l'inspector sur le game object courant, même si un autre asset est ensuite sélectionné;
    7. Applique les modifications au prefab si le game object est lié à un prefab;
    8. Composant transform commun à tous les game objects;
    9. Affichage des composants. La flèche à côté de l'icône permet de masquer ou d'afficher les paramètres du composants; et
    10. Bouton pour ajouter un composant au game object

    Les vue d'inspector peuvent varier selon le type d'asset sélectionné.
